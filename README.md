# 🚀 GPS 출석 체크 시스템

React + Spring Boot 기반의 **GPS 기반 출석 체크 웹 애플리케이션**입니다.

사용자의 현재 위치를 바탕으로 출석 가능 여부를 판별하고,  
당일 출석 기록을 확인할 수 있도록 구현되었습니다.

개발 목표 : AI 툴을 이용하여 하루안에 배포까지 완료하기
→ 스프링을 활용해 최대한 가볍게 구현하는 것이 목표였기때문.

---

## 🛠 기술 스택

| 구분           | 기술                        |
|----------------|-----------------------------|
| 프론트엔드     | React, Axios, HTML5 Geolocation API |
| 백엔드         | Spring Boot, JWT            |
| 인증           | JWT 기반 로그인 / 토큰 인증 |
| 저장소         | Git, GitHub                 |

## ✨ 주요 기능

- ✅ JWT 토큰 기반 로그인 / 회원가입
- ✅ 사용자의 현재 위치 측정 (Geolocation API)
- ✅ 기준 좌표 반경 100m 이내일 경우 출석 인정
- ✅ 하루에 한 번만 출석 가능
- ✅ 오늘 출석한 사용자 목록 테이블로 표시
